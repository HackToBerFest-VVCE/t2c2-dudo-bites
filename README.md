
# AI-Powered Bot-Driven Misinformation Campaign Detection

An AI-powered system to investigate potentially misleading social media content and suspicious bot accounts.

The project analyzes post text, account activity, timestamps, and network interactions to identify possible coordinated misinformation campaigns.

The initial prototype focuses on detecting repeated posts shared by multiple accounts within a short time window.

Future development will explore machine learning, bot-behavior classification, campaign risk scoring, and explainable reports.

The system supports human review and does not automatically censor content.
